# Nerax Website

A hand-coded Nerax landing page and command guide.

## GitHub Pages

1. Create a repository, for example `nerax-website`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. In GitHub: **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

The site uses your Nerax Discord invite and support-server links.

### Custom domain

If you later buy a domain, use **Settings → Pages → Custom domain** and follow GitHub's DNS instructions.

### Important

This starter site is a public landing page/documentation site. Discord OAuth login and a private dashboard require a backend; do not put a Discord Client Secret in browser JavaScript.
